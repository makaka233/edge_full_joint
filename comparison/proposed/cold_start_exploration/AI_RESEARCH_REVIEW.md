# EXP034 Proposed 冷启动均匀探索研究交接

**结论：候选未通过预登记的冷启动门槛。保留原训练探索作为 Proposed 基线。** 五种子各两轮真实联合训练中，首轮极差周期由 23 降到 15，高于上限 11。截尾由 927 降到 266，但 Seed16 由 0 增到 206。三个新初始状态中仅一个同时改善 Reward 和完成 E2E。切回原探索后的 GS9–16 没有新的极差周期，五种子冻结评价均值向好，但存在 Seed17 和持续 0.70 的反例。本轮止于 16 GS，证据范围为启动阶段和 GS16 检查点。

## 研究对象与实验版本

Proposed 使用 `comprised_exp1` 的 v2 紧凑载荷配置。32 个异构节点、52 条无向物理连边、104 个独立有向资源、3,500 个固定接入端点、10 类服务和 28 个串行阶段。CPU 总容量为 366.9185 CU/s，每阶段计算量为旧 EXP029 配置的两倍。原 CPU `finish_pf`、有线平方根 KKT、固定最短路、RAM/SSD、无线共享、连续事件推进和跨期队列均沿用。每期 24 秒，完整合法矩阵瞬时切换，旧阶段沿原指派完成。原 Reward 为 −10 × 惩罚后平均 E2E（秒）再扣持有和切换成本。观察截止是本期结束后 8 秒，截尾请求在评分时计入惩罚，仍可继续物理执行。

Agent-D 沿用 57 维汇总输入、八维 Gaussian Actor、链路边际定价与 EXP029 滞后优势校准。Agent-S 是原 Masked Dueling Double DQN，并在每八期末更新。历史 Proposed 的五份日志重新统计得到 GS1–8 共 23 次 Reward ≤ −20、927 次截尾，GS1–64 共 24 次。旧 EXP029 前 64 GS 的极差次数为零，两轮环境工作量不同。既有冻结事故诊断已用原矩阵、同流与成熟/随机 S 分离局部 CPU 拥塞与随机 Q 偏好。[历史诊断交接](../../../research/COMPRISED_EXP1_COLD_START/AI_RESEARCH_REVIEW.md)

## 唯一改动与工程验证

实验配置增加默认关闭的 `s_uniform_before_first_update`。在实际采集在线转移且 `s.updates == 0` 时，开启的 B 臂令 ε=1，由原 scheduler 对所有合法节点等概率抽样。若回放不足而没有完成优化步，均匀探索继续生效。首次真实更新后立刻恢复 `max(0.05, 0.25 - 0.20 × (GS-1)/511)`，保持原全局时钟。A 臂从起点使用原公式。固定验证、正式独立评价和普通冻结执行始终用 ε=0。诊断入口显式复现训练行为时可以执行对应的冷启动选择，但不调用优化器。

共享训练入口仅在显式携带本轮配置时增加实际 ε、决策前 S 步数和节点派发日志。恢复用实际配置类型校验 checkpoint，继续读取原完整模型、优化器、replay、RNG 和 GS 账本。开关关闭时五个种子的 GS1–16 均与 `comprised_exp1` 原始记录逐期匹配，包括矩阵、潜变量、请求哈希、Reward、请求级完成/惩罚时延和 CPU、无线、有线账本。

- 4 项专项测试通过。覆盖均匀采样与合法掩码、真实物理在线和评估边界、回放不足时继续探索，以及中断恢复与连续运行逐期一致。
- 21 项既有整体服务和对比工程测试通过。正式 16 GS 对照的最大资源守恒残差为 3.14×10⁻¹¹，最大容量残差为 5.69×10⁻¹⁴。两个阶段两臂的永久丢弃均为零。
- 十条在线轨迹均核验随机初始化来源、同请求哈希、正的 D/S 参数变化。前八期 S 更新数为零，第 9 期决策前为 64。两臂每种子最终实际更新 2 D / 128 S，合计每臂 10 D / 640 S。B 在 GS9 以当前全局索引得到 ε≈0.24687。

### 首次更新前的失败路径

五个种子首轮的 40 个 A/B 配对均有相同 D 矩阵和相同请求轨迹。Seed16 的反例发生时 S 仍是随机权重、D/S 均尚未优化。用原随机初始化和真实事件引擎重放 Seed16 首轮，两臂的逐期请求哈希、矩阵、Reward、CPU、截尾和节点派发计数均与正式日志相等。GS8 的节点 23 期内 CPU 注入由 225.43 增至 310.64 CU，而 24 秒能力只有 205.92 CU。期末余量由 34.05 增至 107.36 CU，峰值并发从 17 升至 55，Node 23 实际派发数由 80 增至 114。两臂全网最大有线期末工作均为 2.39 Mbit。

阶段 16 只有节点 23 一个合法位置，占该节点当期 139.92/120.40 CU（A/B）。同一节点还与阶段 7、23、4 的任务共享，其中阶段 23 的支持集为 {23, 31}，实际在节点 23 入 CPU 的任务从 29 增至 50。阶段 7 从 5 增至 14，阶段 4 从 3 增至 13。均匀合法选择逐动作公平，累计工作量仍可能因支持集重叠和不同工作量落到同一个节点。GS8 初始在途请求 21/60、期末 25/100，后者反映同一探索干预在前七期已改变继承队列。该期原始 Reward −16.662/−71.924，截尾 0/48。整轮结果归因于未更新时 S 行为改变及其跨期传播。

GS9–16 的 40 个 A/B 配对中有 22 个部署不同，D/S 都已学习且两臂经验不同。两臂均无极差期、截尾和终局未完成。B 的平均 E2E 高 0.49 ms、平均 P99 高约 96.77 ms，最集中的节点派发份额降低。这八期无法分离回放内容、Q 学习与布局变化对尾部的后续影响。[Seed16 事件回放](../../runs/proposed/cold_start_exploration/diagnostic.seed20261116.gs8.json)

## 16 GS best / last 冻结评价

## 预登记判定与唯一后续建议

| 预登记检查 | 实际 | 判定 |
|---|---|---|
| 首轮极差 ≤11 | 15 | 未通过 |
| 首轮截尾 ≤463 | 266 | 通过 |
| ≥3 种子同时改善首轮 Reward 和完成 E2E | 3/5 | 通过 |
| 次轮极差/截尾不增加，平均 Reward 差 ≥−0.25，平均完成 E2E 相对增幅 ≤5% | 0/0、−0.0126、+0.047% | 通过 |
| 新初始状态联合改善 ≥2/3，合计极差与截尾不增加 | 1/3，8→6、919→56 | 联合改善未通过 |

首轮总体事故减少，GS9–16 未发现严重反弹，冻结均值有改善，同时存在明确反例。**本轮不推进 512 GS 或 5000 GS，不升级，也没有长期收敛结论。** 唯一后续建议是做一次同矩阵、同流的固定调度归因，预先用“各阶段按合法支持集均摊的期望节点计算工作”和节点实际工作量定位像节点 23 一样的支持集重叠，先检验该信号能否在新初始状态复现风险，再决定是否需要新探索机制。
