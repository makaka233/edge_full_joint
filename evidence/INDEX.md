## 字段说明

- `physical_submission_id` 以 run ID 与 GS 唯一定位真实轨迹；GS 是一次训练物理提交，不是优化器步数或时间。
- `e2e_raw` 只统计完成请求；`e2e_penalized` 含原始截尾惩罚；`dropped_requests=null` 意味着永久丢弃不可由观察窗推断。
- D/S 更新数为提交前累计；同一配对或周期批提交后才更新。`actor_loss=null` 表示原轨迹未记录该数值；`critic_loss=null` 表示 D 无 learned Critic，S TD 损失在批更新文件；`checkpoint_id=null` 表示无逐条轨迹绑定的已保存检查点。
- `simulation_seconds` 为实际离散事件覆盖时长，`wallclock_seconds` 为实际此次评价耗时。`evaluation_error` 保留异常原因；未观测或缺失的 GS 不插值，未产生的数值保持 null。
- 图表重生成：`python -m edge_d.cli plot --out runs/figures_regenerated`。本索引由默认归档命令生成；当前模式和历史路径分别见 [主基线](../research/CURRENT_BASELINE.md) 和 [历史](../research/history/INDEX.md)。
