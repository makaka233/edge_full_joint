# EXP012 预注册协议

两种子 20261113/14，物理配置、原 Reward、库存保护、原 Agent-S 和 KEEP/BUILD 冻结。对照使用 EXP010 从随机初始化实际完成的库存、仅高斯组各 256 个训练物理提交。复用其已有原始轨迹，三个组均使用相同训练场景、请求种子、预算及固定验证索引。新组从随机参数重新训练，保持启发式 S。

新策略保留已有库存覆盖骨架。密度头输出各阶段的 Binomial 可选数量偏好，位置头输出可用阶段—节点的 Plackett–Luce 排序。数量的试验次数由骨架与 RAM/SSD 单位可放性决定。样本中只有每阶段各自实际提出的位置前缀被赋概率。两个头都观察当前负载、上/下游可达性、共享 CPU 压力与剩余库存。内部按随机阶段顺序与候选排名一次投影到合法矩阵，原容量检查决定丢弃，记录每个被丢弃的提案。全程只有一次网络前向和每个矩阵一次物理提交。没有副本数配额、在线择优或局部编辑阶段。

正式模型显式保留全网绝对工作比及未经场景中心化的阶段和节点压力。首个可运行试验在正式记录前用于发现只有场景内标准化会折损绝对负载信息，停止了先导运行。下文机制及训练使用补全后的随机初始化。

每两次真实提交更新一次。奇数配对保持位置扰动不变而独立抽取两组逐阶段数量，偶数配对共享各阶段提案数而独立抽取两套位置扰动。未更新头不求梯度。某头的每次更新使用两条独立条件采样的原物理 Reward 差乘对应 log probability 差的一半。配对反事实共用需求和请求流，分别执行，二者均计入预算。Adam 数量 0.012、位置 0.008，范数裁剪 5。旧基线各 128 次高斯更新，新组各 64 次数量和位置更新，共 128 次。固定验证用 EXP010 的 0–7，GS0/16/…/128/160/192/224/256。只用固定平均 Reward 选模型。

先进行有界机制测试，两个种子各做一次数量、一次位置更新并记录真实矩阵、概率及 Reward。按同两条采样路径重算更新前后 log probability，对实测 Reward 较好路径的相对赔率至少应在每种子两个更新中的一个上升，且双方更新法定、梯度有限、资源守恒。另抽样两检查点的真实矩阵做短预算质量检查。机制测试使用单独训练场景和权重，正式训练从同随机参数重新开始。机制正确性不计入正式训练或收益验收。

独立短窗场景 610–621，偶数为自然到达，奇数把到达负载按可知业务工作量调至全网 CPU 的 0.55 倍并对一个区域加 1.35 倍偏好后重归一化，容量未变。冻结旧 DDQN 和启发式 S 分开评价 GS0、128、256、固定最佳。连续队列场景 630–635 在一个 Simulator 中处理 84 秒持续到达的请求，前 14 秒预热，统计 [14,70) 秒到达者至 84 秒，场景按奇偶设置总工作量 0.64/0.82 倍、区域偏好倍率 1.35。评价 GS256 的三组和两种 S。同流保持所有请求，程序统计阶段驻留未结、受限节点利用、积压变化和截尾。连续队列 Reward 不与短窗定义混算。另在自然到达场景 640–645 各抽 4 个实际布局评估 GS0 和 GS256，优质定义为 Reward ≥ −4.8、含罚平均 E2E ≤ 0.45 秒且零截尾。

机制分解在 650–655 用新模型初始/末次两个头做 2×2 配对实测，保留共同随机数及相同场景。位置成对比较时保持每阶段真实提出的数量相同，记录合法投影后数量是否仍相同。新组整体通过要求双种子固定验证末次优于初始且随机布局优质率不退，独立短窗平均 Reward 相对于库存组至少 +0.03、平均 E2E 和 P99 不变差、最差 5% Reward 不降超过 0.10。连续队列要求两种 S 的平均及 P99 不退，截尾数不增。任何新训练真实 Reward ≤ −20 判作未达到可靠性要求，仍计入全部报告。以上为描述性门槛，所有极值保留。
