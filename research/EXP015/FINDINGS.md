# EXP015 训练分布对照与资源信用

## 实验范围

四组为库存协调与 EXP014 节点并行，各自使用原分布和混合分布。每种子每组 256 次完整矩阵物理提交、128 次参数更新。原分布训练与固定验证取 EXP010／EXP014 原始记录，混合组从随机参数重训。GS0 的八个固定物理评价逐点相同，混合组自然训练子集与原分布用相同请求流。此次比较沿用两套现有生成器、各自优化器和固定调度器。

混合训练预先固定每种子 32 场景自然、32 场景 0.40、32 场景区域倾斜的 0.55、16 场景 0.64 和 16 场景 0.72。每训练场景有两次同流物理提交。高并发在完整需求周期持续，训练原 Reward 仍基于两个短窗。独立队列由同一个物理仿真器观察 84 秒持续到达。固定最佳按 13 个检查点各八个自然场景的 Reward 选取，独立评估同时报告该最佳和末次。所有独立评价使用本轮首次采用的场景。

10 项算法及物理回归测试通过。实际日志验证了相同分布内两架构的物理请求流、四组固定验证请求流、独立同场景请求流和冻结调度器对同一矩阵的配对。更新和物理提交分别记录。分析将 CPU 可达压力视为诊断量，物理 E2E、截尾与连续积压依据原事件轨迹。

## 高负载下的原始负峰

库存混合的两条早期极端轨迹都在 0.72 训练档。种子 20261113 的 GS41 与 GS42 在场景 20 使用同一批请求。GS41 的 Reward 为 **−66.42153**，214/929 个请求在观察结束时未完成，已完成请求 E2E 仍达 **2.551 s**，加入截尾惩罚后为 **6.612 s**。GS42 的 Reward 为 **−8.77502**，929 个请求均完成，平均 E2E **0.844 s**。GS41 的最高有线利用率为 **99.73%**，另一分支为 **75.69%**。GS41 的 CPU 理想承载下界是 **0.741**，关键副本甚至多于另一分支。短窗截尾和观测到的链路拥塞共同解释负峰所表现的延迟，单靠 CPU 理想可行性或关键副本总数无法预警。

种子 20261114 的 GS14 与 GS13 在场景 6 匹配。GS14 的 Reward 为 **−22.35229**，平均 E2E 为 **2.216 s**，931 个请求均完成。另一分支的平均 E2E 为 **1.199 s**。最高有线利用率由 **71.29%** 升至 **98.83%**。这一严重负峰不含观察截尾。两例说明高负载尾部既可由真实延迟产生，也可被观察截尾惩罚进一步放大。

混合节点并行的两个种子合计 **512 次训练**没有 Reward ≤ −20 或观察截尾。最差单次为 **−9.15739、−11.50245**，最差 5% 为 **−8.75063、−10.28940**（各 13 点）。库存混合的最差 5% 为 **−15.05641、−11.20993**，两个负峰均发生在前 128 GS。原分布与混合组的原始训练曲线涵盖不同负载，曲线纵向差本身不能衡量模型优劣。

## 学习与后期稳定性

混合节点并行在固定自然场景上的 Reward 从 GS0 的 **−4.55321、−4.64550** 改善到 GS256 的 **−4.39540、−4.60435**。固定平均 E2E 分别从 **432.03 降至 406.61 ms**、从 **439.61 降至 429.48 ms**。原分布节点并行在相同固定场景的末次 Reward 为 −4.27128、−4.51118。混合训练减弱了两种子的自然固定验证收益。

混合节点并行种子 20261113 的固定最佳 GS192 为 **−4.36110**，到 GS256 有所回落。种子 20261114 在 GS160 的固定 Reward 降至 **−4.91794**，到 GS224 仍低于初始化，末次才回升。末次固定 P99 **991.02 ms**，GS224 为 **1,542.82 ms**，后期没有稳定平台。混合库存的固定最佳为 **GS256、GS192**，各自末次 Reward 为 **−4.22302、−4.12902**。

四个新训练组实际物理时间各约 **14,000 仿真秒**，逐阶段调度约 **190.1–192.0 万次**。每组训练及固定验证的实测墙钟约 **1,096–1,104 秒**，包含并行任务的资源竞争。

## 独立 0.55 短窗与资源分配

固定启发式 S 下，种子 20261113 用混合训练将节点并行 Reward **−6.31055 提升至 −5.92961**，平均 E2E **600.86 降至 555.10 ms**，P99 **1,472.49 降至 1,332.29 ms**。同时重训的库存 Reward 从 −5.70089 变为 −5.76776，节点并行的相对 Reward 差由 **0.60966 缩至 0.16185**，约缩小 73%。冻结 DDQN 下同种子的混合节点并行平均 Reward 比混合库存高 **0.10905**，P99 仍高 **42.57 ms**。

种子 20261114 的节点并行 Reward **−6.22784 降至 −6.30479**，平均 E2E **588.65 升至 596.76 ms**，P99 **1,375.29 降至 1,341.76 ms**。混合库存 Reward 是 **−5.58191**，相对 Reward 差由 **0.58838 扩大至 0.72288**。冻结 DDQN 的混合节点并行平均 E2E 和 Reward 也退化。两种子的四个 0.55 场景中，短窗均未出现观察截尾。

启发式 S 下的四个同流场景，种子 20261113 的相对 Reward 差每个都缩小。种子 20261114 只有一个场景缩小。对四个场景做的配对重采样区间分别约为 **[0.235, 0.745]** 与 **[−0.293, 0.024]**，量度是相对 Reward 差缩小值。区间来自各自有限场景，只作敏感性描述。

四个工作量最高的阶段上，种子 20261113 的节点并行平均副本由 **28.00 增至 37.75**，可达 CPU 压力由 **0.323 降至 0.231**。混合库存达到 **61.50 个副本、0.122 压力**。种子 20261114 的节点并行平均 RAM 利用率由 **75.7% 升至 86.2%**，SSD 利用率由 **69.9% 降至 54.1%**，关键副本反由 **29.25 降至 20.50**，可达 CPU 压力由 **0.204 升至 0.366**。该对照显示整体资源占用无法代表高工作量阶段获得的有效承载。

## 连续队列、随机矩阵和固定最佳

0.82 连续队列用启发式 S 时，种子 20261113 的节点并行混合训练将平均 E2E 从 **1,025.99 降至 903.32 ms**，P99 从 **2,472.44 降至 2,202.49 ms**。混合库存在相同流为 **846.06 ms、P99 1,950.36 ms**。种子 20261114 的节点并行由 **890.22 升至 943.41 ms**，P99 从 **2,492.43 降至 2,409.42 ms**，混合库存为 **742.81 ms、P99 1,770.49 ms**。冻结 DDQN 下，0.82 的混合节点并行均值分别 **1,109.32、902.55 ms**，混合库存为 **1,075.30、797.50 ms**。在所有观测队列截止时均完成了请求，但高负载中途积压和尾部延迟依然不同。

种子 20261113 的节点并行混合固定最佳 GS192，在独立 0.55 启发式 S 下取得 **−6.15671**，低于自身 GS256 的 **−5.92961**。该最佳的 0.64 连续平均 E2E **665.96 ms**，好于自身末次的 **686.93 ms**，0.82 则由最佳的 **942.17 ms** 改善至末次 **903.32 ms**。固定最佳不能替代独立压力结果。种子 20261114 的节点并行混合最佳和末次均为 GS256，两者共享真实记录。其他三组的最佳和末次比较见单文件表格。

随机矩阵自然负载高质量样本在节点并行初始为 **7/12、11/12**，混合末次为 **12/12、10/12**。该固定阈值下 0.55 的所有组均为 0/12。独立压力采样的节点并行平均 Reward 在种子 20261113 从原分布末次的 **−6.22687** 改善至混合末次的 **−6.13842**，种子 20261114 从 **−6.29348** 变为 **−6.35974**。档内真实矩阵分布曲线保留全部采样。

## 关键位置的物理边际信用

按预注册执行 32 组同流单副本控制。原分布节点并行的两个种子各有 **3/4** 个已被拒绝的合法关键位置，在补入后提高真实 Reward。混合训练后仍发现 **3/4、1/4** 个此类位置。混合种子 20261113 的场景 901、阶段 19、节点 24 是直接例证。该节点有约 **3.75 RAM、73.08 SSD** 剩余，该位置的条件接受概率仅 **3.17%**。只加这一位使 Reward 增 **0.26240**、平均 E2E 降 **26.54 ms**、P99 降 **231.97 ms**。同种子混合组还有两个已接受副本的净边际 Reward 为负，其中场景 905 的阶段 11、节点 21 被赋予 **97.77%** 条件接受概率，而它没有改变测得的 E2E，只增加了持有和切换成本。

这些位置都经物理合法性核对。共享 CPU 压力、上下游路径、节点 RAM/SSD 余量、局部接受和拒绝概率、按请求记录的 Reward 和延迟，以及逐窗每节点和每有向链路的资源实际量均保留。该对照只切换一个位置，能识别给定完整矩阵及请求流下的边际因果效应。四个场景的抽样不能外推全局最优布局或整个策略的错选率。

## 研究判断

训练分布是重要因素，效果具有种子和调度器依赖。种子 20261113 的启发式 S 达到“差距至少减半且连续队列非恶化”的分布证据，其他配对无法同时达到全部条件。节点并行策略在公平混合训练下仍有高压阶段分配不足、合法高价值位置低概率和长期尾部差距。结果支持当前表示和信用配置存在瓶颈，实验没有分离两者各自的贡献。

库存协调继续作为正式 Agent-D。节点并行与混合训练保留为研究对照。原定预算内的两个种子缺少一致稳定性，本轮未升级算法或训练分布。继续考察预算时应以预先固定的独立样本和策略质量分布判断，本轮数据不足以声称仅增加更新就能解决高负载信用问题。
