# EXP016 库存协调 Agent-D 与原始 DDQN 联合训练

## 在线闭环与信用

每个在线 GS 用随机初始化起步的库存协调 Agent-D 生成完整 28×32 部署。原始 DDQN 在真实请求到达和逐阶段就绪时选择合法节点。事件引擎结算原分配后更新 CPU、逐跳有线和无线活跃资源集合。主分支采集真实掩码、动作、阶段奖励、下一状态与终止标签。S 仍以原始局部阶段奖励训练 Online Q 与 Target Q，使用原 Double DQN 与 Polyak。D 获得当前实际 S 所形成的原始全局 Reward。

每个在线提交另配一次实际物理仿真。反对称高斯潜变量共用解码种子、请求流、S Online Q 指纹、版本、ε 和探索随机数初始状态。只有主分支进入 S 回放。对比完整发生后才执行 D 与 S 更新。因此，配对差不会混入两次 S 参数版本。D 使用两个真实潜变量的高斯对数概率和 Reward 差计算梯度。一个离散矩阵可由多个潜变量生成，这里重算的是实际高斯路径的概率。

D 的损失为 `−0.5 × (R在线 − R配对) × (log p在线 − log p配对)`。采样潜变量在计算分数时保持常数。两条高斯样本的边际分布相同，反对称噪声使两条分数方向相反，因此该式给出同一版 S 下配对物理 Reward 的梯度估计。S 使用按请求阶段记录的原始局部转移，D 信号与 S 的局部 TD 目标含义有别。

联合程序保留原始 20 秒有效预热、两个 6 秒观测窗和最多 8 秒排空。测得的尾部区分真实完成时延与观察截尾。固定及独立短窗使用当前 D/S 贪婪组合。连续队列用同一原事件引擎连续收到请求并追踪跨窗口积压，报告真实延迟和截尾，不套用短窗 Reward。

## 断点与对账

D/S 两套 Adam、S Online／Target、版本、回放环位置和全部观察、Torch RNG 以及日志偏移随完整检查点保存。分别在 GS64、128、256 结束后由独立进程加载检查点继续训练。两种子还从 GS64 单独重放 GS65，在线和辅助物理分支的矩阵与轨迹一致。在线 Reward、请求级延迟和回放数量一致，D 梯度、S DDQN 损失与两边参数变化也精确一致。重放只用于恢复审计。

启动时的 Windows 沙箱进程管道限制发生于 GS0，随后从原随机初始化快照恢复。正式训练的物理比较由独立本地进程运行。串行管道回归重放与正式并行账本的结果精确一致。检查点和权重保留在项目本地运行目录，正式仓库保留复现代码、账本与审计记录。

## 早期高负载负峰的实测形态

种子 20261114 的在线 GS2 原始 Reward 为 **−162.94**。501 个观测请求有 373 个截尾，已完成请求平均 E2E **3.04 秒**，惩罚后 **16.28 秒**。该分支的理想 CPU 下界 **0.692**，真实节点 CPU 峰值利用率 **98.86%**，CPU 资源最大并发 **321**，有线峰值利用率 **45.24%**。同版 S 和同请求流的反事实也有 399 个截尾且 CPU 理想下界只有 0.533。这次负峰对应实际 CPU 积压加截尾惩罚，仅查部署理想承载会漏掉风险。

同种子 GS7 的在线分支没有截尾，均值 **1.32 秒**。另一张部署经相同 S 调度，有线峰值利用率由 **77.93% 升至 98.93%**，有线资源最大并发由 17 升至 101。已完成请求均值 **3.04 秒**，5 个请求截尾，Reward **−31.42**。两种矩阵在同一场景产生不同竞争和真实延迟，且辅助分支从未进入 S 回放。完整序列保留两类负峰。

## 双种子 512 GS 的训练结果

每种子完成 **512 次在线物理矩阵提交、512 次单独记账的配对物理评价、512 次 D 更新、4,096 次 S DDQN 更新**。512 步均观察到 D、S Online Q 和 Target Q 参数变化。在线逐阶段调度动作分别为 **3,751,090、3,770,220**，在线逻辑仿真为 **27,758、27,769 秒**，训练及固定验证的实际墙钟为 **2,136.31、2,133.53 秒**。调度动作含用于原物理测量的预热和排空背景业务。仅在线观测队列生成的 833,404、840,202 条转移进入原回放，保留最新有效环数据。正式配对的 1,024 对轨迹全部通过同请求流、S 指纹、版本、物理 Reward 与高斯路径对账。14 项针对性回归测试通过。

全部在线训练中，两个种子分别有 **1、2 次 Reward ≤ −20**，均出现在前 64 GS。前 64 GS 分别截尾 **22、381** 个请求。后续各 **448 次在线提交**中未再观察到 Reward ≤ −20 或截尾。前 64 GS 的最差 5% Reward 均值 **−18.82567、−55.03440**，GS257–512 为 **−6.06575、−6.16575**。末段有相同预注册压力档比例，平均惩罚后 E2E 为 **457.8、466.6 ms**。这些结果保留了随机初始化和探索时的全部负峰。

## D/S 交叉归因

在学习后的 S 下，只替换初始 D 为末次 D，两个种子的独立 Reward 分别再提高 **2.28945、1.64068**，平均 E2E 下降 **279.47、234.34 ms**。在初始 S 下，只替换 D 却使 Reward 进一步下降 **4.87329、94.45588**，并出现更多截尾。这表明 D 的部署收益依赖实际调度策略。

固定初始 D，只替换 S 为末次模型可使 Reward 提高 **10.63250、93.44966**。使用末次 D 时，训练后的 S 仍有正收益。同一末次矩阵下，训练后的 DDQN 比启发式 S 在短窗平均 E2E 低 **63.9、64.1 ms**。最终收益包含了随机调度的拥塞修复，也包含适配该调度器的部署收益。

每个配对内部严禁更新 S。跨配对仍有联合策略变化，末次保存的回放中位年龄均为 7 个在线 GS，最老分别为 14、15。交叉试验支持联合适配，无法单独识别更新频率或局部奖励对后期收益递减的贡献。BUILD-only 联合学习在本协议的双种子短窗与连续队列达到独立改善，后期尾部风险在受测样本中受到控制。
