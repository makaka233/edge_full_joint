# EXP018 单候选资源感知探索协议

基线为 EXP016 原始 ε-greedy，初始 ε=0.25。唯一新候选 R 在 GS1 将原行为分布与资源代价分布按 25:75 混合，资源权重在 GS1–33 线性归零，GS33 起完全恢复原规则。实际决定由这两个分布中的一次样本产生。评估和贪婪策略始终使用原 DDQN。保持原合法集和原 ε 分支，因此每个合法节点的概率至少为 (1−资源权重)×ε/合法节点数。D、S 从随机参数开始。物理、奖励、探索时钟、目标网络与学习预算均沿用 EXP016。

资源分布只使用原 24 列观测。代价为当前阶段工作 / CPU 容量、目的端既有和在途 CPU 工作时间、空路径传输时间及按有向路径累加的在途有线工作时间之和。工作到达和实际共享分配会变动，因此这只是当前状态的近似。令 s 为合法节点空载计算加传输时间的中位数，使用权重 [1+(代价−最小合法代价)/s]⁻² 后归一。这里没有 CPU 或链路门槛。直接记录资源分支次数，并用冻结相同 S 权重的物理差识别规则的即时贡献。固定验证 ε=0，比较随机初始化与 GS64 时两个均不使用资源偏好的贪婪组合。

因果门槛先用 EXP017 四个登记案例。矩阵、完整流、原 S 权重匹配，采用同一官方短窗和独立影子排空。至少三例正式 Reward 提高 0.5 且影子平均真实 E2E 下降。每例正式 Reward 最多退化 2.0、正式截尾不增加、影子 P99 最多退化 10%。总截尾需下降，至少一例 CPU 并发下降且至少一例有线并发下降，合法节点访问比例每例至少为 A 的 90%，影子观察停止时仍未完成数不得增加。不调整代价或混合参数以迎合这四例。

因果门槛通过才安排双种子同预算 64 GS，每种子 64 在线、64 配对、64 D/512 S 更新。A 沿用 EXP016 原始日志与 EXP017 精确复跑的同种子数据。分别要求 R 严重负峰数少于 A、最差 5% 平均 Reward 至少提高 0.5、最差单次 Reward 与总截尾不退化、前 32 GS 合法节点访问比例不低于 A 减 0.02。固定 Reward、平均 E2E、P99 对 A 的最大非劣容忍分别为 0.05、5 ms、40 ms。通过才从随机初始化产生的同一轨迹续训至 512 GS。两种子的相同独立场景和持续队列与 EXP016 对比 Reward、P99、平均 E2E 及截尾，固定最佳和末次各自报告。最终门槛要求双种子 GS512 的独立短窗总体和 0.55 层 Reward、平均 E2E、P99 与截尾均不劣于 A，0.64、0.82 连续队列的均值、P99 和截尾也不劣于 A。

若候选在任一门槛不通过，停止探索微调，复制原 EXP016 训练账本和 GS512 完整快照到本轮主线目录。从该状态续训两个种子至 GS1024，保留 GS768 和 GS1024 检查点，原 ε 随时钟自然保持 0.05。固定验证沿用历史场景与选模规则。新增短窗 1120–1127，偶数自然、奇数 0.55；新增 84 秒队列 1140–1143，偶数 0.64、奇数 0.82，压力场景区域乘 1.35 后归一。在这批此前未用的场景对 GS512、768、1024 同流评价，不用独立集选择检查点。另在 EXP016 原短窗重测 GS1024 作为历史桥接。各分层报告均值、尾部和截尾，绝对差和正负两类结果均保留。
