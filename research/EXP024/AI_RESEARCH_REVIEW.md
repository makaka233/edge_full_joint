## 唯一训练候选 A

`--s-update-timing period` 每期给原 DDQN 分配 8 次更新。每个边界只追加自上次后已完成且拥有 next state 或真实终止标签的转移，标记使用其派发时的 S 版本和在线 GS。阶段跨期仍占用原物理队列，普通期末不会产生终止样本。最后一期在原排空后执行最后一批更新。排空后仍未完成的合成终止样本单独记账，候选不消费这些样本。有效回放未达到 minibatch 大小时只在同一 episode 内顺延，实际次数和未使用预算逐期记账。基线正式预算为每期 8 次、每个八期 episode 64 次。D 的更新仍在 episode 末按原始物理 Reward、价值基线和原高斯 log-probability 完成一次。Agent-S 的 DDQN 目标、掩码、回放实现和 Polyak 更新沿用原代码。

期末 S 更新使后续行为能使用已完成数据。它改变数据顺序与经验分布，也是需要用同流正式对照检验的效果。单元测试验证跨期动作版本归属、非终止 bootstrap、唯一回放入账、同流、守恒和 episode 边界恢复。恢复验证覆盖 D、S Online/Target、优化器和经验回放及逐期日志的数值一致性。仅测试候选 A。候选 B 的 D 状态和候选 C 的价值基线等待 A 的正式结果。

**验证记录。** 10 项连续训练测试和 3 项原始物理及 DDQN 回归通过。最终代码在原 episode 模式下对种子 20261114、20261115 各复算首个完整八期，16 期物理轨迹与 EXP023 相同。种子 20261114 的主 CLI 双臂各 2 GS，实测各 1 次 D 更新、16 次 S 更新、176 条转移入回放；同流完整闭环还执行了 160 个短期独立对照物理期、离线审计与三类出图。烟测用每期 2 秒和 minibatch 1，属于工程证据。其性能数值不进入 512 GS 验收。[烟测审计](../../runs/results/EXP024/formal.smoke.gs2.review.json)

## 正式实验与复现

首轮用两个早期异常对应的种子 20261114 和 20261115。每臂从随机初始化开展 64 个八期 episode，即 512 个在线 GS。对照使用相同训练流、固定流、物理协议、学习率、minibatch、探索和预算。在项目根目录执行下列 PowerShell 指令，由用户启动正式训练。

```powershell
python -m edge_d.cli adaptive train --experiment EXP024 --seeds 20261114 20261115 --macro-mode redeploy --s-update-timing episode --episodes 64 --periods 8 --period-seconds 24 --eval-every 8 --prefix '.\runs\results\EXP024\base.gs512'
if ($LASTEXITCODE -ne 0) { throw 'Baseline training failed' }

if ($LASTEXITCODE -ne 0) { throw 'Candidate training failed' }
```

恢复时对相应臂追加 `--resume`。两臂结束后执行独立评估及画图。评估用 `--workers 1` 可串行运行。

```powershell
python -m scripts.exp024_evaluate compare --seeds 20261114 20261115 --workers 3

python -m scripts.exp024_report formal --seeds 20261114 20261115 --gs 512
```

已有冻结证据可用 `python -m scripts.exp024_report frozen` 离线复算。仅在需要重做物理诊断时运行 `python -m scripts.exp024_evaluate frozen` 或 `python -m scripts.exp024_evaluate history`。

正式筛选要求两臂同流、实际优化预算一致、D/S 均发生有效学习。前 64 GS 的最差 5% Reward 和严重负峰次数，两种子均不得恶化，至少一种子的最差 5% Reward 改善 0.5。自然 Holdout 的 `best` 和 `last` 分别比较，平均净 Reward 退化至多 0.03，完成平均 E2E 退化至多 1%。两个持续压力档的 P99、截尾和终局未完成不得恶化。突发场景、最差 1% 和单次 Reward、期末积压以及固定曲线单独复核。512 GS 只用于通过机制与早期风险筛选。若通过，再由用户扩至五种子和覆盖 GS1308、GS1779 的预算，用同组末次退化和独立尾风险决定是否升级。

- 两个基线臂分别与 EXP023 对应种子的前 512 GS **全部逐期一致**，包括矩阵、原始 Reward、逐请求完成/惩罚后时延及请求哈希。四份运行清单均登记 `d465dbe999618d882f5df2ecf3cc22f01dd526a9`，随机初始化，单次从 episode 0 启动，均标记 `dirty=true`。清单未保存启动时的工作区差异。
- 两个候选臂都在首个 GS 结束后执行了 8 次 S 更新，随后 512 个边界各完成 8 次。跨期有效样本分别为 4412、4398 条，未延期更新、未排除排空失败的合成样本。两臂各自的回放入账数按种子一致，分别为 703,136、753,201。四臂都在 64 个 episode 中记录到 D/S 实质参数变化。D 平均裁剪前梯度范数为 188.21→182.14 和 181.71→180.95。恢复点、日志偏移、回放入账、物理容量和最优投影均已复核。

- **20261115 GS15** 的 Reward 从 −26.745 提高至 −7.796，P99 从 10.834 降至 1.913 秒，期末积压从 60 降至 8。该期已发生一次 D 更新，两臂有效矩阵相差 5 位。这是改动 S 更新时间后通过真实学习产生的联合效果，无法从这一次线上对照分离 D 和 S 的各自贡献。

### 固定验证与共同环境验收

两臂的固定验证选模位置相同。种子 20261114 的 `best=last=GS512`，末次固定 Reward 为基线 −4.69783、候选 −4.69693。种子 20261115 的 `best=GS256`，固定 Reward 在基线从 best −4.28493 降至 last −4.35464，候选从 −4.27779 降至 −4.36082。候选没有消除该种子的后段回落。

自然档全部通过 Reward 退化至多 0.03、平均 E2E 退化至多 1% 的预设条件。所有 Holdout 均零观察截尾、零终局未完成、零永久丢弃。持续档 8 个检查点配对均出现 P99 退化，其中种子 20261114 的 best 与 last 是同一检查点，因此是 6 个不同的配对。最大退化是种子 20261115 last 的持续 0.70，P99 **1.755→1.816 秒**。三类门槛分别判定为早期尾部通过、自然负载通过、持续负载失败。
