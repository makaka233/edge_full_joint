# EXP028 · 五种子 5000 GS 长训与独立长队列验收

## 研究协议

由 EXP027 的冻结证据进入长期验证。EXP026 的正式验收结论仍为 14／16，候选仍未升级。EXP028 比较原 CPU 运输和 EXP026 原链路边际定价，沿用高斯 Agent-D、原 Agent-S、固定瞬时 REDEPLOY、episode 末 DDQN、原 Reward 和物理环境。[EXP027 冻结诊断](../EXP027/AI_RESEARCH_REVIEW.md) · [EXP026 对照](../EXP026/AI_RESEARCH_REVIEW.md)

五个预定训练种子为 20261113–20261117。两臂使用相同种子及外生流，全部从随机权重开始，各跑 625 个八期 episode，每期 24 秒。每个种子每臂 5000 在线 GS，名义预算 625 次 D 更新、40,000 次 S 更新，实际账本在报告阶段核验。两臂合计十组、50,000 在线 GS。固定验证沿用 EXP023，每 64 GS 一次，另含 GS0、GS5000。按固定验证净 Reward 选 best，另评估 GS5000 的 last。

共同独立环境种子 2802801，场景 28101–28104。自然、突发、持续 0.55 和持续 0.70 分别连续运行 24 期，保留跨期资源与队列。突发第 9–12 期目标负载 0.70。所有种子、臂和检查点使用同一组四个外生轨迹，冻结 D/S，使用原均值潜变量和贪婪 S。该组是成对的共同环境筛选，每个负载类别只有一个外生轨迹，结论不外推为该负载的总体置信区间。沿用 EXP026 的非劣门槛，逐种子逐场景要求 P99 不得上升。候选的独立结果由训练完成后实际账本判断。

## 从项目根目录启动

```powershell
python -m scripts.exp028_run
```

流水线最多并行三组训练。十组完成后才开始独立评估，再生成五种子的完整逐 GS Reward/E2E/P95/P99、固定验证与 Holdout 对照。训练或评估中断后重跑同一指令即可，已有恢复模型续训，已完成训练及经核对的独立评估复用。可用 `--workers 1` 串行运行，或用 `--workers 5` 提高并发。并发只改变执行调度。

所有结果位于 `runs/results/EXP028/`。运行配置、物理配置指纹与 Git 信息写入 `gs5000.protocol.json`。各训练前缀为 `cpu.gs5000.seed<seed>` 和 `link-priced.gs5000.seed<seed>`，使用原 best、last 与 resume_latest。共同独立日志为 `compare.gs5000.seed<seed>.jsonl`。最终汇总为 `formal.gs5000.review.json`，另有逐种子中文 PNG。

烟测命令 `python -m scripts.exp028_run --smoke` 使用单种子、两个 2 GS 短运行和独立的 smoke 前缀。正式 5000 GS 由用户启动。

并发烟测已完成两臂训练、32 个独立短评估周期和绘图。再次运行同一烟测指令时，已完成训练与评估均被复用，独立日志哈希一致。正式前缀在交付时为空。
