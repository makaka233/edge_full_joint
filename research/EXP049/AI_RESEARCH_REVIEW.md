# EXP049 · 自适应部署时机的训练相位覆盖

**工程与轻量验收完成，H1 待正式实验。** EXP049 比较突发训练相位固定与分散，检验高负载、老部署和累积工作同时出现时，Agent-D 的时机模块能否更可靠地调用已训练的部署生成器。正式训练共两种子、两个组别、1152 个训练 GS，由使用者在本地运行。

## 研究依据

EXP043 五种子 GS504 固定验证 Reward 从 −8.747 改善到 −7.097，完成 E2E 从 0.8681 降至 0.6908 秒。EXP047-A 独立 Reward 为 −7.7084，固定两小时为 −7.4376。EXP048 在 A17 突发槽 8 的同状态分叉测得 REDEPLOY 三槽净收益 +4.882，且原训练在既定突发相位外几乎没有高负载 Replay。覆盖不足是待检验的原因。长期价值拟合、状态表达与后期退化仍是可能解释。[EXP043](../EXP043/AI_RESEARCH_REVIEW.md) · [EXP047](../EXP047/AI_RESEARCH_REVIEW.md) · [EXP048](../EXP048/AI_RESEARCH_REVIEW.md)

## 唯一变量与公平性

- A 复用 EXP047-A 登记的 12 条训练轨迹。源码的受控突发基准为 0.32，连续三槽目标负载 0.70，两天分别从第 4 和第 16 槽起。B 仅移动四条突发轨迹中的连续三槽块。每个宏观日用种子私有的相位 RNG 从日内槽 2、3、4、5、7、9 无放回抽四个起点。整个日程在启动前生成。起点避开首槽 BOOTSTRAP、跨日边界及留出的独立评价起点。
- 每组各有四条自然、四条日内变化和四条突发轨迹。每条突发轨迹有六个 0.70 槽和十八个 0.32 槽，两天分别保持相同负载直方图。相位改变可能使实际到达数、资源队列和截尾发生差异。原外生生成协议及各轨迹的请求与人口随机键在同种子的两组间匹配，轨迹内部的队列按各自动作连续演化。
- 两组均使用 EXP047-A 的 17 维 Gate，从相同未训练公共参数开始。策略和 Replay 使用独立 RNG 对象，同种子配对同一初始随机键，使唯一实验变量为突发相位。各自持有 online、target、Adam、Replay、归一化、环境状态和模型文件。保持原第一条自然轨迹拟合后冻结的归一化。前两块都在首次相位干预前。
- 冻结该种子的 EXP043 GS504 D/S。原解码、逐阶段调度、KKT、成本、Reward 和队列不变。日程在物理环境按槽施加，Gate 仍只观察现时及历史的原 17 维状态。KEEP 沿用原矩阵，REDEPLOY 调用原生成器提交合法新矩阵。原生联合学习入口仍保留，后续外部时机策略与 D/S 联合更新需要显式接通信用和梯度来源。

## 正式协议与验收

每组每种子 12 条独立轨迹，每条 24 槽，共 288 GS。每槽为两小时宏观决策机会，使用原 24 秒物理窗口推进。每组预计 12 次 BOOTSTRAP、276 次正常 Gate 决策、264 条可训练转移和 576 次 Gate 梯度更新。固定场景在 GS0、96、192、288 评价并选 best，独立评价统一使用最后的 GS288 last。学习保持原 ε、均匀 Replay、Adam、Double DQN、Huber 和目标网络更新。

独立评价使用 8 条新外生轨迹，每个种子覆盖自然、日内变化、较早突发和较晚突发。日内变化在每天第 7–11 槽采用 0.55，其余槽为 0.32。两个突发剖面分别从每日日内槽 6 和 10 起，延续三槽且目标为 0.70。两组与固定 2/4 小时在每条轨迹请求配对。晚突发另有一个诊断性 KEEP 前缀以检查高负载老布局，早突发诊断从固定四小时轨迹分叉。只在诊断点复制完整队列和事件，施加同一成熟生成器的提案或 KEEP，后续共用固定两小时，比较三个计分槽。正式 A/B 轨迹按其冻结策略自主决策。

共同历史状态使用 EXP048 的 A13 突发槽 8、A17 突发槽 8 和自然槽 9，在四个检查点对账 Q 差。这些历史状态只做回顾性诊断。P4 同时复算每次均匀 Replay 采样，按负载、年龄、CPU 起始积压、时钟相位及动作分层。主要覆盖分组为负载 ≥0.65 且年龄 ≥12 小时，同时保留 CPU 压力的交叉分组。

自动判定要求两种子均增加高负载老布局经验，两动作均有覆盖且单类计数不降。明确的未见探针要求含前 cohort 的三槽绝对净差 ≥0.10，B 的方向准确数在每种子不降且合计提高。每种子独立平均 Reward 至少改善 0.03，完成 E2E 或 P99 至少一项改善，完成 E2E 退化最多 1%，惩罚后 E2E、P99、严重负峰、截尾、终局未完成与丢弃均不增加，轨迹最大 CPU 积压均值最多增加 1 CU。B 在 GS96→192 和 GS192→288 各段固定 Reward 回退不得超过 0.03。覆盖提高但两种子都没有达到 Reward 门槛、E2E 无改善且未见探针未改善时，判作不支持 H1。其他混合或样本不足的情况保留为不确定。独立报告逐种子和逐轨迹列出所有值及固定周期比较，两个种子的结果只用于决定是否值得继续验证。

## PowerShell 命令

在项目根目录执行。训练中断后直接重发原命令，程序从上一完整轨迹边界恢复。已完成的组别自动跳过。

```powershell
Set-Location 'C:\Users\1\Desktop\edge_full_joint'
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'

python -m scripts.exp049_run smoke
python -m scripts.exp049_run train --workers 4
python -m scripts.exp049_run evaluate --workers 4
python -m scripts.exp049_run report
```

也可单独执行任一任务。仅为所选组指定 `--gs 96` 等 24 的倍数可提前停止，后续去掉该参数继续到 GS288，探索计划与固定验证节点保持不变。

```powershell
python -m scripts.exp049_run train --seed 20261113 --arm A --workers 1
python -m scripts.exp049_run train --seed 20261113 --arm B --workers 1
python -m scripts.exp049_run train --seed 20261117 --arm A --workers 1
python -m scripts.exp049_run train --seed 20261117 --arm B --workers 1
```
