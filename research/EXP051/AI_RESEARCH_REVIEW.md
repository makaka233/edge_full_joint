# EXP051 · 同状态双动作物理经验

**工程与轻量验收已完成。** EXP051 以 EXP050 的至多三步 Double DQN 为对照，检验少量同状态的相反动作经验能否改善独立部署时机。B 在已有主轨迹经验之外实际模拟相反动作。成熟部署生成器、Agent-S、物理引擎、Reward 与学习目标保持原样。正式训练与独立评价待用户运行。

## P0 · 已识别的经验缺口

EXP043 的五种子成熟 D/S 保留。EXP050 的正式试验在种子 17 获得平均 Reward +7.2366、完成 E2E −0.5046 秒、四条独立轨迹合计少 885 次截尾。其三步组在四条轨迹分别实际重新部署 18、20、22、19 次，性能接近固定两小时。种子 13 的两组在四条轨迹均始终 KEEP，物理结果完全一致，EXP050 未通过两种子晋级条件。[EXP043](../EXP043/AI_RESEARCH_REVIEW.md) · [EXP050 正式结果](../../runs/results/EXP050/formal-summary.json)

种子 13 的一步组在这两个条件分组均未到访。另三组曾到访高负载老部署，但三个该类决策均为贪婪 KEEP。种子 17 三步组在高 CPU 积压状态有两次探索，两次仍选 KEEP，其余八次为贪婪 KEEP。实际 Replay 至少抽到了这些分组的 KEEP，故两类缺口分别是状态未到访及已到访却未采到相反动作。只有获得相应 REDEPLOY 转移后，原均匀 Replay 才有机会学习其后果。

既有双动作分叉有真实后继。种子 13 的两个 EXP050 独立探针中，REDEPLOY 的三槽物理收益分别为 +1.595 与 +0.620，三步组的 Q 差却为 −1.012 和 −1.015。用该模型重新计算目标时，两臂均在贪婪不一致处截为一步，目标差分别为 −0.078 与 +0.053。种子 17 两个探针的三步目标差为 +0.314、+3.753，物理方向与 Q 一致，且两臂均保有三步。Replay 上的条件均值也不同，例如种子 13 的 KEEP/REDEPLOY 绝对 TD 均值约 9.737/4.451。它们来自不同状态，不能当成同状态的系统性估值偏差。结果支持补充真实对照经验的试验，尚不能唯一归因于动作覆盖或价值拟合。[P0 原始复算](../../runs/results/EXP051/p0.json)

## P1 · 唯一改动与物理、信用账本

- A、B 均从种子对应的未训练 Gate 开始，使用同一 17 维输入、冻结 EXP043 D/S、至多三步 Double DQN、原 Watkins 截断、原均匀 Replay、Adam、Huber 和相同探索/优化预算。归一化只来自主轨迹首块。同一种子两臂各自持有模型、优化器、Replay、策略 RNG、抽样 RNG、归一化与日志；随机种子协议配对。原 EXP050 训练场景与负载计划照用。
- B 每条 24 槽主轨迹默认最多捕获两个状态。在槽 2–11 和 12–21 两窗口，各取首个负载至少 0.55 且部署年龄至少 8 小时，或节点期初积压至少 25 CU 的状态。窗口无匹配时取最后一个合法槽。仅用动作前状态，起点不依赖未来 Reward、测试轨迹、动作或动作结果。可在首次登记时选每轨迹一个起点。
- 用实时物理分叉工具复制事件堆、任务/回调、CPU/链路/无线资源、部署和环境。主轨迹的原 ε-greedy 动作和真实转移作为 factual；只额外模拟相反动作，使用同一阶段、包请求与外生随机键。REDEPLOY 的唯一提案与相同起点的冻结 D 一致，KEEP 保持原矩阵并零切换费。若 factual 是 REDEPLOY，程序直接核对其实际矩阵与分叉记录提案一致。
- 从捕获起点额外推进四槽。首槽执行相反动作，其后由该块更新前冻结的贪婪 Gate 决策。记录各槽物理 Reward、真实后继、此前 cohort 的成熟账本与状态指纹。前三槽提供最多三条连续转移，第 4 槽提供后继观测和正常观测截止推进，首转移进入均匀 Replay，其余两条只用于回报链并按实际贪婪一致性截断。每条奖励仍是同臂的 `r_t = −C_t − L_(t−1)/γ`，按成熟成本记账。分叉名称隔离后继索引，禁止与主轨迹、其他分叉或种子拼接。三槽收益差不作为监督标签。辅助状态和回报只流向 Gate 的价值学习。
- `aux.jsonl` 记录主/辅配对物理数据，`blocks.jsonl` 分别记录实际主/辅助槽、事件数（含尾部 drain）、主轨迹耗时、复制及辅助物理耗时，更新记录保存实际目标长度。辅助日志与恢复快照共用 block 提交边界，恢复先回退未提交日志尾，再从最近完整轨迹开始。已提交配对不会重复入池。

## P2 · 正式预算与独立验收

种子 20261113、20261117，各 A/B 12 条 24 槽主轨迹，均为 288 个主 GS、264 条主转移和 576 次真实优化。固定评价为 GS0/96/192/288。每槽按原 24 秒物理窗口及两小时宏观决策解释。按默认档，B 每种子额外 96 个物理 GS（主预算的 1/3），增加 24 条可采样首转移和 48 条独享连续转移节点。B 结束时辅助经验占可抽样池的 24/288，即 8.33%。实际抽样占比和总墙钟需看报告。A 不做辅助仿真。两种子合计 1152 主 GS，B 另有 192 辅助 GS，固定验证和独立评价另计。

独立评价用 8 条新外生请求轨迹，四个方法共享请求键。每种子含自然、日内强度变化、早突发、晚突发，同时配对固定 2/4 小时与两个冻结 last。受控探针按同状态比较原物理三槽收益及当前贪婪动作。分别报告有限期方向准确数，是否消除严重截尾并缓解积压，以及一条独立轨迹是否出现多种实际完整部署间隔。状态相关性的正面结论要求探针中两种实际收益方向均被模型识别，单一方向采样会使状态相关性证据不足。整体物理收益要求每种子 B−A Reward 至少 +0.03、完成 E2E 下降、惩罚 E2E、P99、极差及失败不增加。与固定 2/4 小时分别核对 Reward 非劣 −0.03、完成 E2E 非劣 +1% 和尾部风险。报告保留全部种子与失败，并单列物理预算、事件数和实际墙钟比较。控制在物理上限内不能替代成本收益判断。

## P3 · 实际轻量验收

在提交 `877272624fe6795865ead61f46bdc3bda8f6128c` 执行。P0 墙钟约 1.72 秒。烟测真实运行 20 个主/固定评价槽和 8 个辅助槽，共 21.13 秒。种子 13 的启用和关闭分叉组合在首次更新前，去掉耗时字段后主轨迹物理账本逐项相同，主策略 RNG 状态一致。主/辅起点的矩阵、队列、观测与请求配对通过。KEEP/REDEPLOY、合法唯一提案、原 Reward、资源守恒也通过核对。

EXP043 原联合训练入口保留。将来接通联合训练时，正式主轨迹真实 REDEPLOY 才进入 D 部署生成的动作信用；KEEP 不产生部署动作梯度，Agent-S 仍用真实逐阶段交互。辅助假设动作不进入 D 或 S 的正式训练记录。本轮未接通外部时机 Gate 的联合梯度，也未联合微调。

## PowerShell 与交付路径

分支 `exp051-gate-counterfactual-experience` 基于 EXP050 `c0a96eb`。正式默认协议已在本地登记。源码及本说明通过原 GitHub 仓库备份。已有 EXP043–EXP050 模型和数据保留。程序支持只运行一个组或种子，恢复沿用原命令。

```powershell
Set-Location 'C:\Users\1\Desktop\edge_full_joint'
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'

python -m scripts.exp051_run p0
python -m scripts.exp051_run smoke

# 以下正式任务由用户运行
python -m scripts.exp051_run train --workers 4
python -m scripts.exp051_run evaluate --workers 4
python -m scripts.exp051_run report
```

例如单独运行种子 17 · B 到首个固定检查点可用 `python -m scripts.exp051_run train --seed 20261117 --arm B --workers 1 --gs 96`。续跑至 GS288 时移除 `--gs`。首次登记另一个协议时可传 `register --max-forks 1`，已有冻结协议会拒绝混用新旧分叉预算。

[runs/results/EXP051](../../runs/results/EXP051/) 保存每组独立的 `best.pt`、`last.pt`、`resume_latest.pt`、四张常规训练账本和辅助物理账本，另有 `protocol.json`、新独立冻结评估、`summary.json` 与 `final-report.md`。绘图从真实日志读出原 Reward、完成与惩罚 E2E、Q 差、动作与实际保持时长、独立性能、经验来源覆盖、TD 误差/目标步长及额外计算成本。原负峰和失败样本完整保留。正式两种子结果和尚未发生的状态相关学习，均不能由烟测推出。
