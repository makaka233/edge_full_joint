# EXP054 预登记协议

从 GitHub EXP053 提交 `23613c1bfbbb1833e41aa374599fea11ad9260ea` 开始。冻结 EXP043 GS504 的 Seed20261113、20261115、20261117 D/S。逐模型对照 EXP044 的完整正式哈希登记，并交叉核对 EXP050/051 中实际使用的种子。现有 Gate 只读并且只对存在同种子历史模型的开局评分。Seed15 缺少正式 EXP050/051 Gate 时保留为空。

## 分层与随机化

固定九条新流，三个模型种子各有自然、迁移、脉冲。各流由 `stable_seed('EXP054-independent-v1',seed,family,'population'/'demand')` 定义人口与场景键。每条流在原环境和 EXP053 持久环境各有一个起点，共 **18 个**。同一流的两种环境共享根键与参考请求率，但请求标记随各自需求演化。每一环境内部所有物理臂逐请求严格配对。每槽请求和原解码键依原 EXP019 规则产生并写入登记。备用解码键由 EXP054 命名空间单独派生。

- 自然样本槽位为种子顺序对应的 4、5、6。脉冲在第 5 槽把 CPU 提供负载指定为 0.65，下一槽按原参考过程恢复。
- 迁移采用第 3 至 9 槽首次可观察的区域或服务热点身份变化。区间无变化即登记第 9 槽，保留未迁移标志。迁移后的留驻时间只用于报告，选择不会读取它。所有流保留 13 槽需求账本。
- 来源以种子顺序加场景顺序（自然、迁移、脉冲）的奇偶分配固定 2 或 4 小时策略。在焦点动作执行前截取完整物理状态。以预先指定的 Seed13 自然和 Seed17 迁移的四个两环境状态作烟测。通过后继续完成登记状态，最多 18 个开局。
- 仅在 Seed13 自然、Seed15 迁移、Seed17 脉冲的两个环境上增加备用键与旧结构臂。与当期原键臂共享 Actor、真实执行环境和真实请求，旧结构缩放到当前总率后仅供提案使用。备用键与旧结构条件各只生成并实际使用一张矩阵。不存在矩阵筛选。
- 独立目录复用已通过守恒核验的 EXP053 物理分叉。首槽执行 KEEP 或唯一新矩阵，之后均 KEEP。评分原始及对齐的一、三槽 Reward，再执行一槽使第三槽到达的请求正常成熟。所有状态保留原队列，所有臂使用 24 秒窗口。六槽取舍在本轮固定为不做。三槽评价涉及给定续策，并非无限期目标或完整部署策略。

## 固定分析与晋级标准

输出一、三槽折扣净收益，主分析按三槽长度折算为每槽。胜负阈值为每槽 0.03，敏感性为 0.01、0.05、0.10。报告逐状态结果与两环境来源分层，推断仅限登记的十八个状态。记录原始 E2E、惩罚后 E2E、P95/P99、截尾、终局未完成、Reward ≤ −20、CPU/链路积压及成本。固定动作基线同时报告永远 KEEP 和永远 REDEPLOY。

可辨识性诊断用岭回归拟合三槽每槽净收益。模型 B 使用实际 17 维向量。模型 C 在同一向量上追加当期 4×10 强度比例、按服务和现有副本 CPU 支持估计的阶段最大压力及节点平均与最大压力。特征用训练折均值和标准差独立标准化，零方差维度除数为 1。岭惩罚固定为 10，截距不惩罚，预测正则取 REDEPLOY。主实验整种子留一，同种子的所有流及两环境都离开训练折。场景压力测试同时留下测试种子和该场景的全部样本，用其他种子及场景训练。已训练历史 Gate 单独报告。物理优势只作为离线标签。

晋级 A 需同时满足以下迹象。持久环境上实质的 KEEP 与 REDEPLOY 机会各至少涉及两个模型种子。17 维留种子预测相对较好的固定动作，平均有限期 regret 至少下降 0.02/槽，并且至少两个种子下降。留场景诊断与主结果无明显冲突。持久环境无新增严重负峰、截尾或终局失败，原键 REDEPLOY 臂的平均完成 E2E 和 P99 相对原环境的增幅分别不超过 10% 和 20%，并审阅逐臂局部积压与配对差异。若相反的正面证据表明只有原环境通过同类信号检查且持久环境退化，选择 B。否则为 C，列出一项最小可改变决策的试验。固定动作比例不参与验收。全程冻结算法，禁止 Gate 正式训练。
