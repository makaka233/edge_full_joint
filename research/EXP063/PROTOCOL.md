# EXP063 · 候选部署感知的自主时机

父提交 `d749c1039b1a26776a3e23e4834e171da89ff404`。冻结 EXP061 结构化组的同种子 GS504 `last` D/S（Seed13/15 权重来自 EXP060，Seed14 来自 EXP061）。EXP061 的结构化组只留下 1 个在线严重槽、零截尾与终局未完成。EXP062 的可选副本 CPU 偏好被拒绝，未进入本轮。历史 Gate 的动作塌缩、归一化不足以修复排序、持续 KEEP 的失效以及单次解码噪声构成风险；保留固定两小时为主对照、固定四小时为参考。

每槽使用原冻结 D 均值及相同解码键，真正决策前生成一张合法候选。首槽从空状态初始化，必部署并排除出时机梯度。此后用一层 32 宽 Tanh 的 Bernoulli Actor–Critic，拼接原 `macro_state()` 及决策前的部署年龄、当前 CPU 队列、候选切换成本、旧/新矩阵的副本量、位差、阶段最大与平均预计 CPU 压力。尺度由物理单位固定，不拟合评估流。训练按 Bernoulli 概率抽样，评价取概率最大动作（平分时 REDEPLOY）。KEEP 不提交候选，REDEPLOY 使用已评分的同一矩阵。无动作配额、强制过载触发、附加奖励、反事实预选或额外物理分支。

每种子 21 条 24 槽轨迹，504 GS，21 次 Gate 更新、483 次自主抽样决策。每条内部沿用即时部署、真实继承队列、原相位需求过程和 24 秒窗口。训练场景按固定顺序循环原/持久热点自然、脉冲及原环境持续 0.55/0.70；脉冲占零基槽 8、9、10，负载 0.65。γ 沿用 0.99。Gate 用真实原 `credit_targets()`，包含仍可受当前动作影响的旧请求 cohort，并保留完整期末计分。以折扣和缩放 Huber 状态值目标和停止梯度的策略优势，Adam 0.001，梯度范数上限 5。只以末端 `last` 进行独立评价。

独立请求/人口键使用 `EXP063-independent-v1` 预登记，覆盖三个种子各六个场景。A 固定两小时、B 学习时机、C 固定四小时，分别在同流同解码键 24 槽完整物理执行，保持各自队列。记录实际矩阵改变次数，保持时长按每槽两小时计，末段右删失独立记账。原物理秒的 E2E 不转换。长 KEEP 中候选压力较低且真实积压上升的槽只标记疑似错过的部署机会；该标记不推断未执行动作的因果收益。

## 晋级门槛

1. 与 A 配对的每个独立场景，B 的严重槽（原始 Reward ≤ −20）、截尾和终局未完成分别不得增加。B 不得出现 A 同槽未出现的新严重槽，若两者均有严重槽则 B 最差 Reward 不低于 A。B 的最大 CPU/有线积压分别不得超过 `max(1.20×A, A+2 CU)` 和 `max(1.20×A, A+1 Mbit)`。
2. 四个常规场景按种子与场景等权，B 的平均原 Reward 至少 +0.03，平均完成 E2E 至少降低 2 ms。至少 2/3 个种子同时改善这两项。每种子常规均值 Reward 可容忍损失最多 0.03、E2E 增量最多 5 ms。每种子常规均值及每个持续压力场景惩罚后 P99 增幅均至多 5%。
3. 独立轨迹中须实际观察到自主 KEEP 和至少一次首槽以后的矩阵变化，才有证据考虑恢复联合训练。只报告动作随需求漂移、部署年龄和 CPU 排队变化的关系，无动作比例门槛。C 仅作参考。

P4 仅在上述独立条件满足后值得另行接通与验证，`all` 只执行冻结 D/S 阶段。联合策略应显式采样潜变量 `z` 并使用 `log π_D(z|s) + log π_G(a|s,z)`；Gate 以 `z` 对应的部署为条件，即使 KEEP，`z` 也影响了决策并应保留第一项的 score。解码与物理轨迹不反传；冻结期使用均值提案，报告不会将冻结收益解释为联合训练收益。
