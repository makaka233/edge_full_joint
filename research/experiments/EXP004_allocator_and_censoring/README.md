# EXP004 — 80 秒连续物理对照与截尾

固定布局、启发式 S 和请求流，仅切换 CPU 分配器。8 个配对场景中 finish_pf/KKT 平均 E2E 0.4210/0.4443 s，两者均无截尾；不改变默认。两条刻意选择的训练压力样本中，finish_pf 截尾 800/412，停止新到达后追加 30 秒有 275/287 个实际完成；KKT 为 6/108。此实验不是训练，不分配 GS，不把截尾称为永久丢弃。
