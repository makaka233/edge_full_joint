# EXP005 · 调度增量消融协议

初步配对重放发现低理想 CPU 下界也会出现负峰，替换原 S 可以恢复部分样本。第二批实验在主协议的部署改动上增加**确定性局部时延先验 + 可训练 DDQN 残差**；与相同种子、相同库存协调解码但没有先验的 arm 比较，并保留原始基线。双种子分别做 S-only/BUILD 联合，各 64 GS。固定采用观测中已有的 CPU 当前未完成工作、在途 CPU 工作、该阶段工作量、路由固有时间和路由积压，统一以秒计，不用未来到达、不做动作筛除。原 epsilon 随机选取所有合法副本的规则保持不变。在线及目标 Q 都包含相同先验；只在网络之间训练和 Polyak 更新残差。此臂是针对前一阶段诊断的独立消融，不用原/新 holdout 调先验权重。
