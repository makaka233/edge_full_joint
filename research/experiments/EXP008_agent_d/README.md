## 同状态矩阵分布

各臂每种子三机制场景均 8/8 个唯一矩阵，未观测到给定扰动下的大量完全碰撞；这不否认 LP/库存与阈值存在多对一。真实配对回报的单步无动量密度方向检验全部通过；实际 Adam 同向数和矩阵哈希见完整指标，潜变量密度不能直接等同某张矩阵概率。

4 个训练外固定分布场景中，每种子 32 个扰动样本：资源残差的初始→末次平均 Reward 13 为 −5.944→−4.651，14 为 −5.364→−4.255；P99 从 1.533→0.916、1.443→0.809 秒；均副本从 65.8→158.9、62.3→143.2。库存协调的对应平均 Reward −5.987→−4.561、−5.201→−4.262。样本支持分布变化，但约两倍以上副本使容量/持有成本权衡尤为重要；不能称新增表示让尾部在所有协议下非劣。下一轮优先查高冗余布局的资源归因和独立泛化，而非增加补丁或恢复 KEEP。
