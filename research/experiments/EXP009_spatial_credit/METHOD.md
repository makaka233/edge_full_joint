# EXP009 · 旧表示审计和空间信用实验

## 8 维到底控制什么

| 轴 | 进入固定解码的位置 | 可学习自由度与固定选择 |
|---:|---|---|
| 0 | 运输优先级、AP 需求加权本地性 | 调节全局本地性，不逐阶段独立选节点 |
| 1 | 运输优先级、节点速度 | 全局速度偏好；与 0 或 2 的效果会因 LP 活跃集耦合 |
| 2 | 运输优先级、本地需求强度/CPU | 全局偏好，不直接看真实队列 |
| 3 | 运输优先级、RAM/SSD 相对占用 | 全局代价偏好；实际库存与回退始终由求解器决定 |
| 4 | 追加副本的全局偏置 | 同时提高/压低绝大多数可选位的边际，不给单个位信用 |
| 5 | 追加副本本地性 | 全局调本地性，位置由本地性、扰动、库存共同决定 |
| 6 | 追加副本的阶段工作量偏置 | 按工作量整组变化，不能单独给关键节点加一个副本 |
| 7 | 原运输每节点算力上限参数 | 改变 LP 约束可行域，不是直接分配节点、链路带宽或时延 |

冻结动作噪声、在固定状态对每轴做 `±0.5` 干预的位差、阶段/节点覆盖、净副本、位置响应八条向量奇异值在 `raw/audit/geometry.jsonl.gz`。后者去除每阶段的均匀密度变化，但不能完全分离排名与稀疏度，不能将 8 条有限差分的秩解释为布局空间的维数。一张 896 位矩阵可以随一次 LP 切换改变几十位，Actor 依旧只控制八个条件均值。固定解码噪声下抽样 64 个潜变量再换解码噪声做第二遍；无观测碰撞不意味着全局没有多对一。

## 变更的不是另一组资源残差

新实验保留现有库存协调运输骨架；骨架仍由原 8 维控制，不声称全矩阵每位均独立学习。对骨架之外的可行位，在一次生成内部按预定随机顺序做 Bernoulli 采样，之前放入的副本会消耗库存。仅不可放入或已有的位跳过；没有 CPU 学习阈值或固定副本配额，不做编辑循环、候选比选或多次提交后只执行最优。

网络共享阶段—节点特征，直接输出每个可选位置的 logit。条件于潜变量及独立的位访问顺序，联合分布是其**实际访问且可选**二元决定的乘积；选择位和拒绝位都计分，强制/跳过不带梯度。最终矩阵由整个访问策略产生；未显式求潜变量及随机顺序积分后的边际矩阵概率。数学上在共享上下文和两潜变量条件下，对方的位扰动独立，故对方物理 Reward 是合法基线。原高斯 score 更新骨架和全局偏好；Bernoulli score 在受访问的位置形成 `(action−p)∇logit`，缩放 0.1 不改变环境 Reward。空间信用比单纯高斯有更细位置分辨，但仍用全矩阵回报，不能称已知每一位的因果贡献。

终点交换实验恢复一个头到其初始参数、另一个仍用终点参数，保持同一条件、同继承的解码随机流与同请求；比较冻结空间/冻结高斯/两头训练/两头初始。它测的是给定训练历史下的组合效应，非独立从头训练的无偏消融，不能做加法归因。全套只用原始 Reward，不改变物理或独立选择条件。
