# EXP009 · 预注册协议

- 两个训练种子 20261113/14；冻结原物理、Reward、启发式 S、原 DDQN、KEEP/BUILD 和联合接口。重新训练原 8 维（仅用于危险分布诊断，128 GS）、8 维库存协调、库存协调骨架 + 条件空间 Bernoulli（各 256 GS 上限）。每 GS 是一张合法矩阵的一次真实仿真；两条反向潜变量样本均计入训练预算，不选择其中最优在线执行。原 DDQN 只用于独立复核，冻结 EXP005 原 BUILD 最佳，无队列先验、零探索。
- 空间版本随机初始共享特征网络，输出层零使其不预装学习结果；固定原库存协调骨架（不是整张矩阵），第二步按固定随机顺序，以 Actor 的条件 Bernoulli 决定每个可行放置位。只掩蔽骨架已有位和确实装不下的位置，无 CPU 新阈值、固定副本配额或 Reward 选优。相同训练时钟下高斯均值用原反向 score；每支空间 score 用另一支 Reward 作独立基线（给定同场景、两个潜变量，Bernoulli 噪声独立）。两参数组各使用 Adam 0.003、梯度范数上限 5；空间损失乘 0.1 是固定更新尺度，不改 Reward。
- 先做有界机制审计：历史尖峰原矩阵逐点复现，固定潜变量值和原请求流，只切换库存协调，记录骨架、回退、最紧阶段与节点队列；同时对两个训练种子、三个固定需求状态，以固定解码扰动做 8 轴 ±0.5 干预。比较位变化、阶段/节点范围、总副本变化、结构投影：把 8 条差分在「去除该阶段的行均值」后用奇异值谱量化局部位置响应，另单列每轴数目/占用影响。固定同扰动采 64 个高斯潜变量测重复（分母为无序样本对），另对每样本换解码扰动以辨别解码随机性。局部有限差分秩上限是 8，不当作完整全局分布的维度估计。
- 固定均值验证：场景 0–7，GS 0/16/…/128/160/192/224/256。空间放置评估也保留固定随机数，并非逐位贪心。分布探针：固定验证场景 20/21，GS 0/32/64/128 及学习臂 256，每场景 8 张同扰动索引、同请求流样本；记录原始 Reward、P99、唯一矩阵和平均位级 Hamming、阶段/节点副本边际、危险比例（Reward≤−20）、高质量比例（Reward≥−4.8且 E2E≤0.45 秒且零截尾）。这些探针计为额外物理提交，不用于选模。
- 继续训练条件：通过 score/合法性/资源守恒机制检查，空间臂 GS1–128 的最差期≥库存协调对应预算最差期−10 Reward，且灾难提交数不比对照多 2；不满足则报告失败，不拉长预算。优先报告公平预算 GS128；后 128 GS 是预设延长趋势。最终固定最佳按同一固定集平均 Reward 选择（独立 holdout 不选模），并保留 GS0/128/末次，场景 holdout 160–171；两类 S。空间臂额外剥离：同一终点冻结/恢复不同头，使用相同潜变量均值和同随机数的 optional 反事实，比较终点高斯头+初始空间头、初始高斯头+终点空间头、初始两头、终点两头；学习权重敏感性不算在线挑选。
- 成功证据需双种子同时比自身 GS0 改善，且相对库存协调同预算独立 Reward 与 E2E 不系统恶化，P99/最差/灾难样本数不恶化，冻结 DDQN 不系统退化。空间头同骨架增加收益才说明是额外学到，并非仅换固定采样顺序。若出现平台，只能结合后段、样本分布和固定物理反事实区分 A/B/C；不能证明达到全局上界。所有异常及负峰保留。
